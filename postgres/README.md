# Postgres Examples

## `supabase-etl/`

Streams row changes from a Supabase Postgres publication into RawTree with
`supabase/etl`.

```sh
npm run postgres:supabase
```

See [`supabase-etl/README.md`](./supabase-etl/README.md) for Supabase setup,
required environment variables, and replication slot cleanup.
